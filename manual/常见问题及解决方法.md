# 成绩单透镜 常见问题及解决方法

适用版本：**v1.9.8**　·　适用系统：Windows 10 / 11（64 位）
文档版本：2026-11-18

> 说明：先按主题找，再看现象。每条都给出「怎么判断 / 怎么解决」。涉及数据的操作会标明风险。
> 手册正文见《使用说明书》。

---

## A 安装与启动（6 条）

### A1 双击安装包没反应，或 Windows 提示「已保护你的电脑」

**现象**：SmartScreen 弹「Windows 已保护你的电脑」，或双击后没动静。

**原因**：程序没有代码签名证书，Windows 对**新下载**的 exe 会先拦一下。

**解决**：
1. 点「更多信息」→「仍要运行」；
2. 若被 Defender 直接删掉，去「Windows 安全中心 → 保护历史记录」里恢复并允许；
3. 确认文件来自官方仓库的 Release 页，文件名与版本号对得上。

⚠️ **不要**为了运行程序关闭杀毒软件或把整个磁盘加白。

### A2 安装时提示需要管理员权限

**解决**：安装向导默认装到当前用户的 `%LOCALAPPDATA%\Programs\Transcript Lens`，**不需要管理员权限**。如果提示要管理员，说明你双击的是系统级安装变体或文件被改过——重新从仓库下载。实在要装到 `C:\Program Files`，才需要管理员。

### A3 启动很慢，第一次打开要等十几秒

**原因**：单文件 exe 启动时要把运行库解压到临时目录；新下载的文件还会被杀毒软件全盘扫描一次。

**解决**：
1. 第一次慢是正常的，第二次起通常 2~4 秒；
2. 如果每次都很慢，检查安全软件是否对每次启动都做完整扫描；
3. 便携版放在**本地磁盘**（不要放 U 盘或网络盘），启动会明显更快。

### A4 提示「Could not create temporary directory」

**原因**：单文件 exe 解压失败，常见于 `%TEMP%` 目录异常（空间不足、权限被改、条目太多）。

**解决**：
1. 清理 `%TEMP%`（Win+R 输入 `%TEMP%`，删掉里面的旧文件）；
2. 把 exe 放到一个**普通文件夹**（例如 `D:\Tools\成绩单透镜\`）再双击，不要放在压缩包里直接运行；
3. 换用安装向导版。

### A5 出现两个「成绩单透镜」图标

**原因**：装过旧版（旧名字）又装了新版。

**解决**：从 v1.9.8 起，安装时会自动清理旧名字的快捷方式。如果还有残留：
1. 右键多余图标 → 属性，看目标路径；
2. 删掉指向不存在文件的快捷方式；
3. 重新运行一次安装包修复。

### A6 想换电脑 / 想用 U 盘带走

**解决**：
1. 关掉程序；
2. 把 `%LOCALAPPDATA%\SGMS\` 整个文件夹复制到 U 盘；
3. 在新电脑上装好同版本程序，把文件夹复制回 `%LOCALAPPDATA%\SGMS\`；
4. 用原来的账号密码登录，成绩和档案都在。

> 便携版 exe 也可以直接放 U 盘，但**数据目录仍在 `%LOCALAPPDATA%`**，换机器时要单独拷。

## B 注册、登录、找回（9 条）

### B1 注册页看不到「邮箱」「验证码」两栏

**原因**：这台电脑没有配置发信服务（绝大多数个人用户都是这种）。程序自动切成**本地模式**：不需要邮箱验证，注册成功后直接显示找回码。

**解决**：正常填账号、密码、确认密码，注册即可。弹出的找回码窗口**务必保存**（见 B2）。

### B2 找回码窗口关掉了 / 忘了保存

**后果**：找回码只显示一次，程序不存明文，也不会再寄。

**解决**：
1. 如果你还**记得密码**：立刻登录 → 个人中心 →「重新生成找回码」，用当前密码换一串新的，**这次一定保存**；
2. 如果**已经忘了密码**且没保存找回码：数据无法解密，只能在登录页重新注册一个新账号（旧成绩库留在磁盘上但打不开）。这是设计上的取舍：没有后门。

### B3 点「发送验证码」提示本机没有配置发信服务

**原因**：注册页的邮箱验证只在**管理员配好 SMTP** 的机器上可用。

**解决**：本地模式下不需要邮箱验证，直接填账号密码注册即可。若你确实需要邮箱收码（例如多人共用一台配置好的机器），请联系给你装程序的人。

### B4 登录提示「账号或密码不正确」

**排查**：
1. 账号名区分大小写吗？按注册时原样输入；
2. 密码是否误触了大写锁定；
3. 是否记混了别的软件密码。

**解决**：确定密码忘了就走「忘记密码？」（见 B5）。

### B5 忘记密码怎么找回

**前提**：手里有注册时保存的**找回码**。

**步骤**：
1. 登录页点「忘记密码？」；
2. 填账号；
3. 填找回码（区分大小写，可保留短横线）；
4. 设新密码 → 「重置密码」。

重置后**成绩一条不丢**。

### B6 找回码输进去提示不对

**排查**：
1. 字符是否抄错（尤其 `0` 和 `O`、`1` 和 `I`）——程序生成的码**不含**这些易混字符；
2. 是否用了**旧的**找回码（重新生成过的话，旧码已失效）；
3. 账号是否对（找回码是与账号绑定的）。

**解决**：还有密码就登录后重新生成；彻底没有就只能重新注册（见 B2）。

### B7 换了新密码后，原来的成绩还在吗

**在。** 重置密码只换「包裹库密钥的那把锁」，成绩库本身没动。登录后智育分析、成长档案、奖学金页都应当能看到原来的数据。

如果登录后是空的：先确认登录的是**同一个账号名**；再看 `%LOCALAPPDATA%\SGMS\u_*` 目录是否还在。

### B8 「7 天内自动登录」是做什么的

勾选后，程序在本机保存一个**免密码凭证**（7 天有效），下次打开直接进主界面。

**建议**：
- 自己专用电脑：可以勾；
- 宿舍/机房/家人共用：**不要勾**；
- 已勾了想取消：个人中心 →「退出登录」，下次不要勾。

### B9 个人中心改密码 / 重新生成找回码要什么

- **改密码**：要旧密码 + 新密码；
- **重新生成找回码**：要当前密码（生成需要解开库密钥），新码同样只显示一次，旧码立刻失效。

## C 导入成绩（9 条）

### C1 导入了但提示「没识别出任何课程」

**原因**：程序找不到表头行，或课程列没有可识别的信息。

**排查**：
1. 表里有没有一行同时包含「姓名」或「学号」；
2. 课程列名是否带学分，例如 `高等数学(5学分)`；
3. 是否把整张表放在第二个 sheet 里（程序默认读第一个 sheet）。

**解决**：按提示把表头改成「姓名 + 课程名(学分)类别」，再导一次。程序会把前几条警告列出来，照着改即可。

### C2 班级号填什么

格式：**字母、数字、短横线**，1~32 位，以字母或数字开头。例如 `CS2301`、`2023-1`。

⚠️ **不能写中文**（如「计算机2301」会被拒绝）。中文班级名建议用拼音缩写或编号代替。

### C3 为什么导入后要我核对课程和学分

因为学分决定加权。程序把「从表头抠出来的学分」原样摆给你看，**你不点确认，它绝不开始算**。宁可多点一下，也不要用错学分算出一个错的加权分。

### C4 学分不对 / 少了一门课

**解决**：
1. 取消导入；
2. 回 Excel，把学分写进课程名括号：`线性代数(3学分)必修`；
3. 类别也写上（必修/限选/选修），免得被当成「未标类别」；
4. 重新导入。

### C5 提示分数超过 100

**原因**：表里有 >100 的分数（例如加成后的 101）。程序会把它**排除在加权分母之外**，但仍算「这门考过」——所以奖学金「每门 ≥90」可能会把它算达标，而智育加权却不含它。

**解决**：先核对原表，确认是不是录错了。确实有加分政策的，导出成绩时按学校口径换算成百分制再导。

### C6 同一个学期导了两次，会重复吗

不会静默覆盖。程序会弹窗问：**覆盖 / 跳过 / 全部覆盖 / 全部跳过**。导入结束会报告「覆盖 N 条 / 新增 M 条 / 跳过 K 条」。

建议：导错表时选「覆盖」，只是补一门课就选「跳过」再单独处理。

### C7 支持老版 .xls 吗

支持。程序**按文件内容**选读取引擎，不看扩展名——所以扩展名写成 `.xlsx`、内容其实是老格式的表也能读。

### C8 表里没有学号怎么办

能导入，但会用姓名当身份键。**同名同学会串号**。程序会在状态行黄条提示「有 N 名学生没有学号」。

**解决**：尽量在表里补上学号列再导；确实没有的，注意同班不要有同名。

### C9 导入后表格是空的 / 状态行停在「正在解析…」

**排查**：
1. 文件是否被 Excel 打开着（Windows 会锁文件）——关掉 Excel 再导；
2. 文件是否在 OneDrive 等同步盘里且未下载完；
3. 表格是否太大（几千行以上）——等一会，或拆成班级分批导。

若仍不行：设置 → 检查更新旁边看版本号，把 `%LOCALAPPDATA%\SGMS\logs\app.log` 末尾几行发给帮你排查的人。

## D 均分与预警（6 条）

### D1 加权均分和算术平均为什么不一样

- **加权均分**：Σ(成绩×学分) ÷ Σ学分，学分大的课权重大；
- **算术平均**：所有科目等权平均。

程序里「智育分析」给的是加权，「学期侧写」顶部大字是算术平均（标签会写明）。两个数不同是正常的。

### D2 空成绩算 0 分吗

**不算。** 空 / `-` / `/` / 「未选」表示**没选这门课**，学分不进分母；数字 `0` 表示**缺考**，学分进分母并按 0 计。

这就是为什么有的人少一门课均分反而更高——空缺不拖后腿，0 分会。

### D3 三档口径怎么选

| 口径 | 算什么 | 场景 |
|---|---|---|
| 必修 | 只算必修 | 看专业课硬实力 |
| 必修+限选（默认） | 必修 + 限选 | 评奖学金常用 |
| 全部 | 加选修和未标类别 | 看总盘子 |

**选修默认剔除**，这是刻意的：必修、限选、选修是三个独立类别。

### D4 红标代表什么

- 红：挂科（<60）或缺考（0 分），逐门列出；
- 黄：接近警戒线；
- 没有标记：当前口径下没有需要提醒的。

切换口径后红标会**重算**——分母变了，判定基础也变了。

### D5 表头三列都叫「加权均分」，怎么区分

三档口径的列头**故意同名**：这一列装的永远是「学分加权平均分」，变的是「算了哪几类课」。当前档位看右上角按钮和顶部状态行。

### D6 为什么我看到的均分和班里统计的不一样

逐项核对：
1. 口径是否相同（必修 / 必修+限选 / 全部）；
2. 空成绩和 0 分是否按同一条规则处理；
3. 是否有 >100 的分数（会被排除出加权分母）；
4. 学分是否一致（尤其体育、实验课）。

## E 奖学金（7 条）

### E1 最终成绩怎么算的

```
最终成绩 = 学年智育加权（必修 + 限选）× 0.7 + 德育分 × 0.3
```

学年智育**固定用必修+限选**，不受智育分析页按钮影响；只在同班级、同学年内排名，只算大一到大四。

### E2 德育分没录会怎样

按 0 参与测算，但结果表里会备注「德育分未录入，按 0 计」，表格里那一格是**空白**而不是 0。

**建议**：录齐再测算，否则排名会失真。

### E3 德育分怎么录最快

1. 在 Excel 里选好一列（顺序与页面名单一致）→ Ctrl+C；
2. 点表格第一个「德育分」格子 → Ctrl+V；
3. 检查无误 → 「保存德育分」。

也可用「批量导入」上传班委的《品行诚信与素质测评表》，程序会先预览、坏行单独列出。

### E4 特等奖怎么判定

两个条件同时满足：

1. 最终成绩进入**一等奖名额范围**；
2. **每门已考课程**原始成绩都 ≥90。

细节：**不占名额**（拿特等的人移出名额池，后面的人往前补）；默认**不叠加**，勾「允许特等叠加一二三等」才显示「特等+一等」，统计两边都数；只检查真考了的课，缺考（0 分）算考了，拿不到特等。

### E5 名额改了但结果没变

改完名额要点「保存名额」，再点「开始测算」。只改数字不点保存，页面不会重算。

### E6 班级下拉框里没有我的班

班级来自导入时填的「班级号」。检查：
1. 导入时班级号是不是填错了/填了中文；
2. 是不是在**另一个账号**下导入的（数据按账号隔离）；
3. 点一下「重新读取」。

### E7 学年选不了 / 提示成绩范围不完整

奖学金按学年算。你只导了一个学期时，页面会标「仅上半学年」，这时可以录德育分，但排名与奖项要等学年成绩齐了再开放。

**解决**：把同班的另一个学期也导进来（同学年），再回来测算。

## F 档案与侧写（5 条）

### F1 成长档案里没有我导的学生

**排查**：
1. 导入是否成功（智育分析页有数据吗）；
2. 是否点过「重新读取」；
3. 学生是否被**归档**了——搜索框输入「已归档」看看。

### F2 学期顺序乱了 / 时间轴对不上

学期标签来自导入时选的「成绩范围」。检查每份成绩选的学期对不对；顺序按「大一上 → 大四下」固定排列，不按导入时间。

### F3 侧写内容能改吗 / 是 AI 生成的吗

- 侧写里的数字是**本地算出来的**，不来自 AI；
- 「AI 侧写」区块是可选功能，只有装了本地模型才会生成文字；
- 生成的是**初稿**，要判断请结合课程明细自己看。

### F4 改学号后原来的成绩不见了

正常路径下，改学号会把成绩历史、侧写、聊天记录、德育分键一起迁过去。如果迁移失败（只提示不中断），旧记录可能还挂在旧学号下。

**解决**：改回原学号再改一次；或到「成绩明细」里核对。操作前建议先导出备份。

### F5 删除学生和归档有什么区别

| 操作 | 数据 | 还能看到吗 |
|---|---|---|
| 彻底删除 | 先清关联数据再删主档 | 不能 |
| 归档 | 全部保留 | 搜索「已归档」可见 |

只想让名单清爽一点，用**归档**。

## G GPA（6 条）

### G1 GPA 和加权均分是什么关系

没有换算关系。GPA 是按你选的方案把每门课换算成绩点再平均；加权均分是百分制加权。**GPA 只影响显示**，不影响加权和奖学金。

### G2 内置了哪些方案

六套：细分 4.0（原方案）、标准 4.0、标准 5.0、4.3 制、WES、五级制。默认「细分 4.0（原方案）」。

### G3 自定义方案怎么存不下去

校验规则：
1. 至少 2 档；
2. 最低分从高到低排；
3. 最后一档最低分必须是 0；
4. 绩点随分数升高不降低；
5. 绩点在 0~5 之间。

按提示改对应档位即可。

### G4 等级制成绩（优/良/中）怎么换算

在「等级映射」里写 `优=95, 良=85, 中=75, 及格=65`（按你学校的口径）。程序会先映射成百分制，再走 GPA 方案。

### G5 改了方案，以前的成绩会变吗

原始成绩不变；**显示**的 GPA 会按新方案重算。想对比，可以建两个自定义方案来回切。

### G6 最多能建几个方案

最多 10 个自定义方案（内置六套不算）。不够用时删掉不用的再建。

## H 模型与 AI（5 条）

### H1 一定要装模型才能用吗

不需要。成绩导入、分析、档案、奖学金、GPA 全部不依赖模型。模型只影响「AI 侧写 / AI 辅导」这类文字生成。

### H2 下载推理核心失败

**常见原因**：本机没装 Python / pip 不可用 / 网络被拦。

**解决**：
1. 程序失败时会把**完整命令**摆出来，点「复制命令」；
2. 自己开一个命令行窗口粘贴执行；
3. 装好后回模型中心点「重新检测」。

程序**绝不会**在后台偷偷下载或静默安装。

### H3 模型列表里为什么有些行点不动

那是 🔴「困难」档：内存不够。整行不可选（不是不勾，是点不动）。换小一点的模型，或换台内存更大的机器。

### H4 内存明明够，还是显示「勉强」/「困难」

内存探测可能失败（虚拟机、权限受限）。探测失败时程序**一律放行**，不会误判成困难。若仍显示困难，检查是不是把「可用内存」当成了「总内存」——程序比的是总内存。

### H5 本地 AI 会不会把我的成绩传出去

不会。推理全部在本机完成，当前版本**不包含任何云端大模型调用**。模型文件也是从公开仓库直接下载到 `%LOCALAPPDATA%\SGMS\models\`。

## I 更新（5 条）

### I1 检查更新提示「还没有发布任何发行版」

仓库还没发正式 Release，不是故障。过几天再试，或直接去仓库页看。

### I2 提示「检查失败，请手动访问仓库」

网络不通或被拦。程序只读一次版本号，超时 5 秒就放弃。手动去仓库 Release 页下载即可。

### I3 装了新版但版本号没变

**原因**：同版本号不提示更新，也可能装的是另一个同版本的包。

**解决**：设置页确认版本号；对一下安装包文件名；需要换就手动覆盖安装（先导出备份）。

### I4 更新会覆盖我的数据吗

不会。安装包只替换程序文件，数据在 `%LOCALAPPDATA%\SGMS\`，独立于安装目录。首次打开旧数据会做一次自动升级，升级前自动备份。

### I5 需要管理员权限才能更新吗

装在当前用户目录（默认）不需要；装到 `C:\Program Files` 才需要。

## J 数据与报错求助（6 条）

### J1 数据存在哪，能不能直接看

`%LOCALAPPDATA%\SGMS\`。磁盘上成绩**只有密文**（`.enc`），直接打开是乱码——这是设计，不是损坏。

### J2 怎么备份最稳

1. 设置 → 导出 → **含姓名版**，存一份 Excel（最省事）；
2. 完整备份：关掉程序，复制整个 `%LOCALAPPDATA%\SGMS\` 到别处。

恢复：把目录拷回原位，用原密码登录。

### J3 忘记密码 + 没有找回码，还有救吗

没有。密码和找回码是仅有的两把钥匙，都是本地生成、本地保存，程序没有后门，也不会向服务器求助。只能重新注册新账号。

### J4 想彻底清空所有数据

程序内：设置 → 删除成绩库（**两次确认**，不可恢复）。
彻底清干净：删库后卸载程序，再手动删除 `%LOCALAPPDATA%\SGMS\` 目录。

⚠️ 删之前先导出备份。

### J5 报错了，怎么把信息给帮我排查的人

错误弹窗里有「复制错误信息」按钮，点一下会把 traceback + 日志路径 + 日志末尾复制到剪贴板，直接粘贴发过去即可。

也可以手动取 `%LOCALAPPDATA%\SGMS\logs\app.log` 的最后几十行。日志里**不写密码**。

### J6 界面显示空白 / 点了没反应

**先试三步**：
1. 关掉程序重开；
2. 换一页再切回来；
3. 看 `%LOCALAPPDATA%\SGMS\logs\app.log` 末尾有没有 ERROR。

仍然不行：用「复制错误信息」把日志发出来。不要自己删 `users.json` 或 `app.salt`——删了数据就永久打不开了。
