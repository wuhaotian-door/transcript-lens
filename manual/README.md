## 重新生成截图

```bash
# Windows / Git Bash，需本机装好 PySide6 与 pandas/openpyxl
env -u PYTHONHOME -u PYTHONPATH C:/Users/<你>/anaconda3/python.exe manual/tools/capture_shots.py
```

脚本做的事：

1. 在 `.tl_tmp/manual_root` 建一个**假账号**（张老师 / Demo12345），不碰 `%LOCALAPPDATA%`；
2. 用 `tests/fixtures/fake_grades.xlsx` 驱动真实导入流程（文件选择框、确认弹窗都由桩替代）；
3. 每张图用 `QWidget.grab()` 抓真机渲染结果（**不要用 offscreen**：本机 Qt 找不到字体目录，中文会变方框）；
4. 图写到 `manual/images/`，覆盖同名文件。

> ⚠️ 截图里全部是假数据（张三、李四、CS2301）。**不要**把真实学生成绩截进仓库。

## 待补截图

`截图清单.csv` 里状态为「待补」的三张：

- **S09 同学期冲突弹窗**：需要一个已有成绩的账号，对同一学期二次导入；
- **S20 更新对话框**：需要联网，或临时注入一个假版本号让对话框出现。

补拍时按上表编号命名，覆盖同名文件，并把 CSV 的状态改成「已拍」。

## 写作口径（与程序界面一致）

- 程序名统一写「朝夕工作台」；安装目录可出现英文 `Transcript Lens`。
- 按钮名用「」包住，且必须与界面逐字一致。
- 术语：学分加权平均分（智育加权）、计算口径、学业画像（侧写）、成长档案、找回码、本地 AI 推理核心、脱敏版。
- 不写内部实现（自检、闸门、加密算法名、源码路径）；不写「待实机确认」这类内部词。
