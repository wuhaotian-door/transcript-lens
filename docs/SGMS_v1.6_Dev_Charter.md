## 一、技术栈（最终确认）

| 层 | 选择 | 备注 |
|----|------|------|
| GUI | **PySide6>=6.6** | 不用 PyQt6（GPL传染），不用 tkinter（已淘汰） |
| 打包 | PyInstaller `--collect-all PySide6` | 单 exe，当前 228MB |
| 加密 | PBKDF2 + Fernet（core/crypto_store.py） | 磁盘只存 .enc |
| 邮箱 | smtplib（仅 SMTP 465），授权码存 AppData | 不硬编码，不落仓库 |
| AI | 本地模型预留接口 / 云端可选（用户主动） | 见第六节红线 |
| 表格导出 | openpyxl | 不联网 |

## 二、铁律（违反即重写）

1. **core/calculator.py / core/parser.py / core/validator.py / tests/ 一个字符不许改**
2. **密码/授权码/找回码/库密钥：绝不 print、不回显、不进日志、不进异常消息**
3. **找回密码流程**：邮箱是找回码存放处，不是重置通道。库密钥只被密码包裹，忘密码只能靠注册时生成的 24 位找回码解开。详见 `core/recovery.py`
4. **同名学生数据绝不串**：所有侧写/档案/意愿的索引键必须是**学号**，废弃纯姓名索引
5. **不发明未定义的规则**：奖学金换算比例已定为智育70%+德育30%，不许改；特等条件每门≥90，不许放宽
6. **旧 tkinter 代码全部删除**，不在仓库里留 `.bak` 或注释掉的旧代码

## 三、联网红线（v1.6 更新）

### ✅ 允许
| 场景 | 条件 |
|------|------|
| SMTP 发邮件 | 仅找回密码流程，用户主动点击"发送验证码"触发 |
| 辅导员手动启用云端大模型 | 需在设置页手动开启 + 手动输入 API Key，仅在点"深度评估"时调用，不静默 |

### ❌ 禁止
| 场景 | 原因 |
|------|------|
| 自动更新检查 | 静默联网 |
| telemetry / 埋点 / 崩溃上报 | 任何数据外传 |
| `requests` / `httpx` 用于非 SMTP / 非用户主动 AI | 防 Agent 偷懒乱联网 |
| 激活码联网校验 | 阶段二已定方案 A（本地年份比对） |

### 📌 selfcheck 断言更新
SMTP 和"用户主动 AI"不再判为 FAIL。Agent 需更新 `selfcheck` 中对应的断言逻辑。

## 四、奖学金测算规则（v1.6 新增，完整定义）

### 4.1 数据组织
- 导入成绩表时**必须人工输入班级号**（QLineEdit，非空，字母数字或短横线）
- 按班级号建文件存加密库：`class_{班级号}` → 该班所有学生成绩 dict 列表
- 学号从成绩表解析，作为学生唯一键

### 4.2 排名公式

最终成绩 = 智育加权（口径①）× 0.7 + 德育分 × 0.3

纯文本
- 智育加权：来自 calculator 输出的总加权（全口径）
- 德育分：0-100 整数，人工输入（辅导员/班委），支持 Excel 粘贴批量录入

### 4.3 名额分配
- 每个班级独立配置：一等 X 名、二等 Y 名、三等 Z 名
- 配置存加密库：`class_{班级号}_quota.json.enc`
- 配置 UI：QSpinBox 输入，保存按钮写库

### 4.4 特等奖（特殊）
- 条件：最终成绩进入前 X 名 **且** 每门科目原始成绩 ≥ 90 分
- 不占一/二/三等名额
- 默认不与其他奖项叠加（设置页可选"允许叠加"）
- 校验需遍历 `parser` 返回的原始 `courses` 列表，判每门 `score >= 90`

### 4.5 测算输出
- 班级内按最终成绩降序排名
- 结果表格列：排名 | 姓名 | 学号 | 智育分 | 德育分 | 最终成绩 | 奖项 | 备注
- 着色：一等金、二等银、三等铜、特等紫
- 底部统计：总人数、参测人数、各奖项实际/名额
- [导出结果] → Excel（openpyxl）

## 五、UI 架构规范

### 5.1 窗口
- 无边框：`setWindowFlags(Qt.FramelessWindowHint)` + `setAttribute(Qt.WA_TranslucentBackground)`
- 主容器 QFrame：圆角 12px + `QGraphicsDropShadowEffect`（blurRadius=15）
- 自定义标题栏：关闭/最小化按钮 + 鼠标拖拽
- 全局字体：`QApplication.setFont(QFont("Microsoft YaHei UI", 10))`

### 5.2 页面切换
- `QStackedWidget` + `QPropertyAnimation`（opacity 0→1，≤250ms）
- 切页锁：`_switching` 标志 + 看门狗 1500ms 强制作废
- 禁止滑动切换（会闪）

### 5.3 登录流程

启动 → splash（0.8s）→ 检查 session token

├─ 有效 → 跳过登录 → 欢迎页（1.5s 时间问候）→ 主界面

└─ 无效 → 登录窗 → 登录成功 → 淡出 → 欢迎页 → 主界面

纯文本
- 欢迎页问候：05:00-11:59"早上好" / 12:00-17:59"下午好" / 18:00-04:59"晚上好"
- 显示 "{时段}，${用户名}"

### 5.4 侧写辅导页（列表模式）
- 左侧：学生搜索框（实时过滤）+ 列表
- 右侧：选中学生的侧写卡片（肖像 + 意愿 + 提纲）
- 意愿索引：学号（非姓名）
- 搜索：QLineEdit + `findItems` + `MatchContains`

### 5.5 智育分析页
- 顶部：班级号输入 + "导入成绩表"按钮
- 筛选按钮：必修 / 限选（含选修） / 全部（Toggle 组）
- 表格列：姓名 | 总加权 | 仅必修+限选 | 红标原因 | 操作
- 表头从 `SCOPE_COLUMNS` 推导，**禁止手写元组**
