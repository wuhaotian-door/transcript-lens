## 一、课程分类（核心纠正 ⚠️）

**必修、限选、选修是三个完全独立的课程类别，绝不混同。**

| 类别 | 标识 | 说明 |
|------|------|------|
| 必修 | `required` | 专业必修课，必须修读 |
| 限选 | `limited_elective` | 限制选修课（有选课范围限制） |
| 选修 | `free_elective` | 自由选修课（任意选） |

### 口径定义（三口径）

| 口径 | 包含类别 | 用途 |
|------|---------|------|
| 口径① 总加权 | 必修 + 限选 + 选修（全部） | 全局总评 |
| 口径② 仅必修+限选 | 必修 + 限选（不含选修） | 主修能力评估 |
| 口径③ 仅必修 | 仅必修 | 核心课底线 |

> 之前版本中"选修归属限选"的说法**已废弃**。选修是独立类别，在口径①中计入，口径②③中不计入。

### 成绩处理规则（不变）
- 补考不覆盖原成绩
- 同名课出现两次取成绩高那次（学分用那次的，不叠加不平均）
- 空单元格 = 未选跳过
- 数字 0 = 缺考计入
- 文本型数字强转 float

## 三、铁律

1. **core/calculator.py / core/parser.py / core/validator.py / tests/ 一个字符不许改**
2. **密码/授权码/找回码/库密钥：绝不 print、不回显、不进日志、不进异常**
3. **找回密码**：邮箱是找回码存放处，不是重置通道。忘密码只能靠注册时生成的 24 位找回码
4. **同名学生绝不串数据**：所有侧写/档案/意愿索引键必须是**学号**
5. **不发明未定义规则**：奖学金比例已定为智育70%+德育30%，不许改；特等每门≥90，不许放宽
6. **旧 tkinter 代码全部删除**
7. **表格表头从 SCOPE_COLUMNS 推导，禁止手写元组**（已踩过坑）
8. **必修/限选/选修在代码中必须作为三个独立枚举值处理**，任何将选修归入限选的逻辑都是 bug

### ✅ 允许
| 场景 | 条件 |
|------|------|
| SMTP 发邮件 | 仅找回密码流程，用户主动点击触发 |

- telemetry / 埋点
- `requests` / `httpx` 用于非 SMTP / 非用户主动 AI

### 📌 selfcheck 更新
SMTP 和"用户主动 AI"不再判为 FAIL。

## 五、奖学金测算规则

### 5.1 数据组织
- 导入成绩表时**人工输入班级号**（非空，字母数字或短横线）
- 按班级号建文件存加密库：`class_{班级号}` → 该班所有学生成绩列表
- 学生唯一键：**学号**（从成绩表解析）

### 5.2 排名公式

最终成绩 = 智育加权（口径①：必修+限选+选修 全口径）× 0.7 + 德育分 × 0.3

纯文本
- 智育加权：calculator 输出的总加权（含所有三类课程）
- 德育分：0-100 整数，人工输入，支持 Excel 粘贴批量录入

### 5.3 名额分配
- 每个班级独立配置：一等 X 名、二等 Y 名、三等 Z 名
- 配置存加密库：`class_{班级号}_quota.json.enc`
- UI：QSpinBox 输入

### 5.4 特等奖
- 条件：最终成绩进入前 X 名 **且** 每门科目原始成绩 ≥ 90 分
- 不占一/二/三等名额
- 默认不叠加（设置页可选允许叠加）
- 校验遍历 `parser` 返回的 `courses` 列表，逐门判 `score >= 90`

### 5.5 测算输出
- 班级内按最终成绩降序排名
- 结果表格：排名 | 姓名 | 学号 | 智育分 | 德育分 | 最终成绩 | 奖项 | 备注
- 着色：一等金、二等银、三等铜、特等紫
- 底部统计：总人数、参测人数、各奖项实际/名额
- [导出结果] → Excel

## 六、UI 架构

### 6.1 窗口
- 无边框：`FramelessWindowHint` + `WA_TranslucentBackground`
- 主容器 QFrame：圆角 12px + `QGraphicsDropShadowEffect`（blurRadius=15）
- 自定义标题栏：关闭/最小化 + 拖拽
- 全局字体：`Microsoft YaHei UI, 10`

### 6.2 页面切换
- `QStackedWidget` + `QPropertyAnimation`（opacity ≤250ms）
- 切页锁 + 看门狗 1500ms 强制作废

### 6.3 登录流程

启动 → splash（0.8s）→ 检查 session token

├─ 有效 → 欢迎页（1.5s 时间问候）→ 主界面

└─ 无效 → 登录窗 → 登录成功 → 淡出 → 欢迎页 → 主界面

纯文本
- 问候：05:00-11:59"早上好" / 12:00-17:59"下午好" / 18:00-04:59"晚上好"
- 显示 "{时段}，${用户名}"

### 6.4 智育分析页
- 顶部：班级号输入 + [导入成绩表] 按钮
- **筛选按钮（三个独立 Toggle）**：
  - [必修] — 只显示必修课程相关
  - [限选] — 只显示限选课程相关
  - [选修] — 只显示选修课程相关
  - 可多选组合，默认全选（显示全部三类）
- 表格列：姓名 | 总加权(全口径) | 仅必修+限选 | 仅必修 | 红标原因 | 操作
- 表头从 `SCOPE_COLUMNS` 推导

### 6.5 侧写辅导页（列表模式）
- 左侧：学生搜索框（实时过滤）+ 列表
- 右侧：选中学生的侧写卡片
- 意愿索引：学号
- 搜索：`findItems` + `MatchContains`

### 6.6 成长档案页
- 左侧：学生选择
- 右侧：学期时间轴 + 趋势 Δ + 定型/可救分区
- 数据来自 `core/archival.py`

### 6.7 设置页
- 激活码输入
- 邮箱找回配置（SMTP）
- AI 助手开关（本地/云端）
- 导出功能

### 6.8 个人中心
- 当前账号、切换账号、修改密码（需库密钥+验旧密码）
